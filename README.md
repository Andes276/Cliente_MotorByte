# Cliente MotorByte 👤🚗

Proyecto desarrollado en Java con Spring Boot para la gestión de clientes, como parte del ramo de Desarrollo Full Stack.

## Descripción

Este microservicio permite administrar información de clientes, incluyendo:

- Registro de clientes
- Consulta de clientes
- Actualización de información de clientes
- Persistencia en base de datos
- Migraciones automáticas con Flyway

---

# Tecnologías utilizadas

- Java
- Spring Boot
- Maven
- MySQL
- Spring Data JPA
- Flyway
- REST API
